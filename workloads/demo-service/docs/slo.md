# Demonstration SLO

The following is a demo objective, not a customer production commitment.

| Indicator | Demonstration target |
|---|---:|
| Availability during normal mode | 99.5% illustrative target |
| p95 API latency in normal mode | Less than 500 ms |
| Readiness detection | Within the configured probe window |
| Rollback recovery | Demonstrated and measured during rehearsal |

The production SLO must be defined from customer requirements, traffic patterns,
dependencies, and operational capacity.
